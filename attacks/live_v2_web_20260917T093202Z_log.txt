Unlike classic jailbreaks, these attacks assume the model behaves exactly as designed -- the flaw is in the surrounding system, not the model itself. The pattern shows up wherever an agent ingests content from an untrusted source (a web page, an email, a shared document) and that content is placed into the same context window as the agent's real instructions, with no marker distinguishing the two. If the agent also holds write or send capability, the untrusted content effectively gets to drive those tools.
