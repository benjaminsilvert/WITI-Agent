# screenshots/

Terminal-capture evidence for the Phase 1 "before" proofs in `PORTFOLIO_PLAN.md`. One
image per proof, named:

```
vuln_<ID>_<tool>_run.png
```

e.g. `vuln_H_read_inbox_run.png`, `vuln_E_search_notes_run.png`. Each write-up
(`attacks/MANUAL_VULN_<ID>.md`) links to its screenshot from its Result section — the
image should show the full terminal window: the command that was run and its complete
output in the same frame.
